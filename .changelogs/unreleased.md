## New

- **Pipe routes in the world** – placed machines show the blocks of pipe between them, and the hatch the pipe leaves from. That hatch sits where the machine actually allows it (a Distillation Tower's input stays on the bottom, and each distilled fluid leaves from its own height — Benzene from Wood Tar on layer 5). A 2× card pipes each placed machine — the upper one to the upper one, a leftover to another hatch on the last — and each run is sized on its own share. Each item or fluid takes its own hatch and its own blocks — Light Fuel and Fuel do not share, and a single-block machine gives each one its own side — and the pipes join at corners so a run looks like one line. The coloured wire follows those blocks. A run no longer walks through a neighbour and loops back into the controller, and a pipe only docks the face it leaves from. In the gear, under In the world, Shared bus joins machines moving the same thing onto one pipe.
- **Pipe sizes in the world** – a wire between two placed machines names the item or fluid pipe that can carry what that wire moves. The smallest pipe that fits, and more than one when a single pipe can't.
